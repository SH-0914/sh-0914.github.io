# 더 스파이크 크로스 공략집

캐릭터 · 스킨 · 게임 모드 · 재화를 정리하는 공략 사이트입니다.
**내용 수정은 관리자 모드에서만** 할 수 있고, 관리자 모드에는 **내가 만든 관리자 계정(아이디 · 비밀번호)으로만** 들어갈 수 있어요.

- 방문자: 게시된 내용을 보기만 할 수 있어요. (편집 버튼이 보이지 않아요)
- 관리자: 맨 아래 **관리자** → 아이디 · 비밀번호 로그인 → 사이트의 모든 내용을 고치고 **게시하기**

> 🔒 비밀번호는 사이트 코드 어디에도 들어있지 않아요. (웹사이트 코드는 누구나 볼 수 있어서, 코드에 넣으면 바로 노출돼요)
> 계정과 비밀번호는 Firebase 에 안전하게 저장되고, 로그인 확인도 Firebase 서버가 해요.

로그인과 내용 저장에는 구글의 무료 서비스인 **Firebase**를 씁니다.
처음 한 번만 아래 '1. Firebase 연결하기'를 따라 해 주세요. (약 10분)

## 폴더 구조

```
ThespikeWeb/
├─ index.html              페이지 뼈대
├─ css/style.css           디자인 · 색상 · 애니메이션
├─ js/
│  ├─ firebase-config.js   ★ Firebase 연결 설정 (처음 한 번 입력)
│  ├─ content.js           기본 내용 (게시 전에 보이는 예비 내용)
│  ├─ characters.js        기본 캐릭터 (게시 전에 보이는 예비 내용)
│  ├─ app.js               화면 동작
│  └─ admin.js             관리자 모드
├─ firebase/firestore.rules  Firestore 보안 규칙 (Firebase 콘솔에 붙여넣기)
├─ tools/미리보기.bat        내 컴퓨터에서 로그인까지 되는 미리보기 서버
└─ images/                 (선택) 사이트 폴더에 직접 넣는 이미지
```

## 1. Firebase 연결하기 (처음 한 번)

### ① 프로젝트 만들기
1. <https://console.firebase.google.com> 에 내 구글 계정으로 로그인 (Firebase 를 관리하는 용도예요)
2. **프로젝트 만들기** → 이름 입력 (예: `thespike-guide`) → Google 애널리틱스는 꺼도 됨 → 만들기

### ② 웹 앱 등록 → 설정값 복사
1. 프로젝트 첫 화면에서 **웹 아이콘 `</>`** 클릭
2. 앱 닉네임 입력 (예: `공략집`) → **앱 등록** (호스팅 체크는 안 해도 돼요)
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 **`js/firebase-config.js`** 에 그대로 옮겨 적기

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "thespike-guide.firebaseapp.com",
  projectId: "thespike-guide",
  storageBucket: "thespike-guide.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> 이 값들은 원래 웹사이트에 공개되는 값이라 올려도 괜찮아요. 실제로 누가 고칠 수 있는지는 ④의 규칙이 서버에서 막아 줍니다.

### ③ 아이디 · 비밀번호 로그인 켜기
왼쪽 메뉴 **빌드 → Authentication** → 시작하기 → **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정 → 저장
(아래의 '이메일 링크(비밀번호가 없는 로그인)'는 꺼 둔 채로 두세요)

### ④ 관리자 계정 만들기 (내 아이디 · 비밀번호)
1. Authentication → **사용자** 탭 → **사용자 추가**
2. **이메일** 칸에 `내아이디@thespike.example.com` 형식으로 입력
   예) 아이디를 `myid` 로 쓰고 싶다면 → `myid@thespike.example.com`
   (Firebase 는 계정을 이메일 형식으로 만들어서, 아이디 뒤에 이 주소를 붙여요. 실제 메일은 가지 않아요)
3. **비밀번호** 칸에 내가 쓸 비밀번호 입력 → **사용자 추가**
4. 목록에 생긴 계정의 **사용자 UID** 를 복사해 두세요 (⑥에서 써요)
5. (권장) Authentication → **설정** 탭 → **사용자 작업** → **'생성(가입) 사용'** 체크 해제 → 저장
   → 다른 사람이 사이트를 통해 계정을 새로 만들 수 없게 막아줘요.

사이트에서 로그인할 때는 **아이디만** 입력하면 돼요. (`@thespike.example.com` 은 자동으로 붙어요)
실제 이메일 주소로 계정을 만들었다면, 로그인할 때 **이메일 주소 전체**를 입력하세요.
(이때 비밀번호는 그 이메일의 원래 비밀번호와 상관없는, Firebase 전용 비밀번호예요. 같은 비밀번호를 쓰지 마세요)

### ⑤ 데이터베이스 만들기
왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기** → 위치는 **asia-northeast3 (서울)** 추천 → **프로덕션 모드**로 시작 → 만들기

### ⑥ 관리자 등록 (보안 규칙)
1. Firestore Database → **규칙** 탭 → 있던 내용을 지우고 `firebase/firestore.rules` 파일 내용을 붙여넣기
2. `여기에-관리자-UID` 를 ④에서 복사한 **사용자 UID** 로 바꾸고 → **게시**

> 💡 UID 복사가 귀찮다면: ⑦에서 로그인했을 때 "관리자로 등록되어 있지 않아요"가 뜨면, 그 창의
> **'사이트 주인이신가요?'** 를 펼쳐 **규칙 복사** → 규칙 탭에 붙여넣기 → 게시. 내 UID 가 이미 들어가 있어요.

### ⑦ 로그인해 보기
1. `tools` 폴더의 **`미리보기.bat`** 더블클릭 → 브라우저에 `http://localhost:5500` 이 열려요
2. 사이트 맨 아래 **관리자** → 아이디 · 비밀번호 입력 → **로그인**
3. 관리자 모드가 켜지면 성공! 처음에는 상태가 **'아직 한 번도 게시 안 함'** 이에요.
   **게시하기**를 한 번 누르면 지금 내용이 Firebase 에 올라가고, 그때부터 사이트는 게시된 내용을 보여줘요.

> 비밀번호를 바꾸고 싶다면: Authentication → 사용자 → 계정 오른쪽 ⋮ → **비밀번호 재설정**은 메일이 가지 않으니,
> 계정을 삭제하고 ④처럼 새로 만든 뒤 ⑥의 UID 를 새 UID 로 바꿔 주세요.

## 2. 관리자 모드 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 게임 소개 · 모드 · 재화 고치기 | 각 섹션 제목 아래 **✎ 이 섹션 편집** → 오른쪽 편집 창 |
| 로고 · 환영 문구 · 메인 문구 · 맨 아래 문구 | 도구 막대 **사이트 설정** |
| S+ 출시 · 복각 날짜 기록 | 출시 · 복각 섹션의 **✎ 이 섹션 편집** → **S+ 캐릭터 모두 불러오기** → 날짜 입력 (편집 중에는 섹션이 보여요) |
| 업데이트 트레일러 올리기 | 업데이트 섹션의 **✎ 이 섹션 편집** → **+ 업데이트 추가** → 유튜브 주소 붙여넣기 (편집 중에는 섹션이 보여요) |
| 공식 채널 링크 추가 · 수정 | 공식 채널 섹션의 **✎ 이 섹션 편집** (주소만 넣으면 아이콘 자동) |
| 캐릭터 스탯 · 특성 · 스킨 | 캐릭터 카드 클릭 → 오른쪽 편집 화면 (공격력 · 수비력 · 스피드 · 점프력을 최소 ~ 최대 슬라이더로 조절) |
| 캐릭터 추가 | 도구 막대 **+ 캐릭터** 또는 목록 끝의 **새 캐릭터 추가** |
| 등급(S+ ~ A-) · 별명 · 포지션 · 테마 색 | 캐릭터 카드 클릭 → 기본 정보 (목록은 항상 등급순) |
| 신규 캐릭터 강조 켜기 / 끄기 | 캐릭터 카드 클릭 → **신규 캐릭터로 강조** 스위치 |
| 사이트에 반영 | **게시하기** — 누르는 순간 방문자에게 보여요 |
| 고친 것 취소 | **되돌리기** — 마지막 게시 상태로 |
| 방문자 화면으로 확인 | **미리보기** (오른쪽 아래 버튼으로 다시 편집) |

- 고친 내용은 바로 화면에 보이고, **게시하기 전까지는 이 브라우저에만 임시 저장**돼요.
  창을 닫아도 다음에 로그인하면 "편집하던 임시 저장본이 있어요"로 이어서 할 수 있어요.
- 큰 수정 전에는 **백업 → 백업 파일 내려받기**로 전체 내용을 파일로 받아두세요.
- 목록 항목은 ↑ ↓ 로 순서 변경, ✕ 로 삭제할 수 있어요.

## 3. 이미지 올리기

편집 화면의 **이미지 올리기** 버튼으로 내 컴퓨터의 이미지를 고르면, 사이트가 알맞은 크기로 줄이고 고화질 WebP로 압축해서 Firebase 에 저장해요. 이미지 파일을 따로 옮길 필요가 없어요.

| 용도 | 권장 원본 | 사이트에 저장되는 크기 |
|---|---|---|
| 캐릭터 · 스킨 | 세로 3:4, **900 × 1200px 이상** | 긴 변 1200px (+ 카드용 560px) |
| 스크린샷 | 가로 16:9, 1600 × 900px 이상 | 긴 변 1920px (+ 목록용 800px) |
| 로고 | 배경 투명 PNG | 긴 변 1200px |
| 모드 · 재화 아이콘 | 정사각형, 투명 PNG | 256px |

- 화면에는 작게(카드 약 220px, 상세 창 최대 400px) 보이지만, 저장 크기가 2~3배라 고해상도 화면에서도 선명해요.
- 캐릭터 상세 창의 이미지 아래에 **해상도 안내**(선명함 / 흐릿할 수 있음)가 나와요.
- 도트(픽셀) 그림이면 **사이트 설정 → 도트(픽셀) 그림 모드**를 켜세요.
- 배경이 투명한 캐릭터 PNG라면 **사이트 설정 → 캐릭터 카드 이미지 → 이미지 전체 보이기**를 추천해요.
- 경로 칸에 `images/...` 처럼 사이트 폴더의 파일 경로를 직접 적어도 돼요.

## 4. 인터넷에 올리기

GitHub Pages 로 운영해요. 주소는 `https://sh-0914.github.io` 예요.

1. 코드를 고친 뒤 **GitHub Desktop** 을 열면 바뀐 파일이 보여요. Summary 에 한 줄 적고 **Commit to main → Push origin** 을 누르면 1~2분 뒤 사이트에 반영돼요. (횟수 제한 없음)
2. 주소(도메인)를 새로 쓸 때는 Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인**에 추가해야 관리자 로그인이 돼요.
3. 캐릭터 · 날짜 · 이미지 같은 내용 수정은 사이트에서 로그인해서 **게시하기**만 하면 되고, 다시 올릴 필요가 없어요.

## 5. 알아두면 좋은 점

- **무료 범위**: Firebase 무료 요금제(Spark)로 충분해요. 결제 수단 등록이 필요 없어요.
  방문자가 아주 많아져 하루 무료 읽기 한도(5만 회)를 넘으면 그날은 기본 내용(content.js)이 대신 보일 수 있어요.
- **관리자 추가**: ④처럼 계정을 하나 더 만들고, 규칙의 `['UID1']` 을 `['UID1', 'UID2']` 처럼 늘리면 돼요.
- **로그인 시도 제한**: 비밀번호를 여러 번 틀리면 Firebase 가 자동으로 잠시 막아줘요.
- **색상 바꾸기**: `css/style.css` 맨 위의 `--accent`(주황), `--cyan`(하늘) 값
- **Firebase 연결 전**: 관리자 로그인 없이 `js/content.js`, `js/characters.js` 내용만 보여요.
